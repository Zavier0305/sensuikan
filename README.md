# 海戦ゲーム（潜水艦）オンライン対戦版

紙とペンで遊ぶ「5×5マスの海戦図」ゲームを、2〜5人でオンライン対戦できるブラウザゲームです。フロントエンドはビルド不要の素の HTML / CSS / JavaScript、バックエンドは [Supabase](https://supabase.com/)（Postgres + Realtime + Row Level Security）を使っています。

## ルール概要

- 全員で **1枚の5×5海戦図（列 A〜E、行 1〜5）を共有** します。
- 各プレイヤーは同じ種類・耐久1の船を3隻、他のプレイヤーには秘密で配置します。自分の船同士は重ねられませんが、他プレイヤーの船とは重なってもかまいません。
- 移動はありません。自分の番では **攻撃のみ** 行います。
  - 攻撃できるのは、自分の船があるマス以外のすべてのマスです。
  - 攻撃したマスに他プレイヤーの船があれば、そのマスにいる**全員の船が同時に沈みます**（耐久1なので1発で沈没）。
  - 攻撃したマスに自分の船が隣接していれば、命中の有無に関わらず「水しぶき」として近くに自分の船がいることが分かります（索敵の手がかり）。
- 船を3隻すべて沈められたプレイヤーは脱落します。最後まで残った1人の勝利です。

## セキュリティ設計について

このゲームは「自分の船の位置は他人に知られてはいけない」という隠し情報ゲームです。そのため:

- 船の位置を保存する `ships` テーブルは Row Level Security (RLS) で保護されており、**本人の行しか読めません**。
- `rooms` / `room_players` / `ships` / `events` への直接の書き込み（INSERT/UPDATE/DELETE）はすべて禁止されており、変更は必ずサーバー側の関数（`attack` など、`SECURITY DEFINER` で実行）経由でのみ行われます。これにより、ブラウザの開発者ツールなどから直接テーブルを書き換えて不正をすることを防いでいます。
- 命中判定・水しぶき判定・全滅判定・手番の管理はすべてこのサーバー側関数の中で行われ、クライアントは結果だけを受け取ります。

`supabase/schema.sql` に上記をすべて実装した状態で用意してあります。実際に手元の PostgreSQL で全プレイヤーのシナリオ（配置→攻撃→水しぶき→重なりマスでの同時撃沈→全滅→勝利判定→ゲーム終了後の操作拒否）を再現して動作確認済みです。

## 遊び方

`script.js` に既定の Supabase プロジェクト（URL / publishable key）を埋め込んであるので、追加のセットアップなしにそのまま遊べます。

```sh
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

または `index.html` を静的ホスティング（GitHub Pages など）にデプロイしても動作します。ビルド手順は不要です。

1. ニックネームを入力して「ルームを作る」を押すと、5文字のルームコードが発行されます。
2. 他のプレイヤー（合計2〜5人）は、同じページを開いてそのルームコードを入力し「ルームに参加する」を押します。
3. 各プレイヤーがそれぞれ3隻を配置し、ホスト（ルームを作った人）が「ゲーム開始」を押すと対戦開始です。
4. 自分の番になったら、緑色に表示される攻撃可能なマスをタップして攻撃します。最後まで生き残ったプレイヤーの勝利です。

### 自分の Supabase プロジェクトを使いたい場合

タイトル画面の「接続設定を変更」から、別のプロジェクトの URL / anon(publishable) key を入力すれば切り替えられます（この端末のブラウザにのみ保存されます）。自分のプロジェクトを新しく用意する手順:

1. [supabase.com](https://supabase.com/) でアカウントを作成し、新しいプロジェクトを作成します。
2. 左メニューの **SQL Editor** を開き、このリポジトリの `supabase/schema.sql` の内容をすべて貼り付けて実行します。
3. 左メニューの **Authentication > Providers** を開き、**Anonymous Sign-Ins** を有効にします（ニックネームだけで参加できる匿名ログインを使うため）。
4. 左メニューの **Project Settings > API** を開き、**Project URL** と **anon / publishable key** を控えて、アプリの接続設定画面に入力します。

## ファイル構成

- `index.html` — エントリーポイント（Supabase JS SDK を CDN から読み込み）
- `style.css` — 見た目
- `script.js` — 画面描画とSupabaseとの通信（バニラJS、状態に応じて `#app` を再描画するシンプルな実装）
- `supabase/schema.sql` — テーブル定義・RLSポリシー・サーバー側関数（RPC）一式
