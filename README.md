# 海戦ゲーム（潜水艦）

紙とペンで遊ぶ「5×5マスの海戦図」ゲームを、1台の端末でパス&プレイ（画面を回して交互に操作）形式で遊べるようにしたブラウザゲームです。ビルド不要・依存ライブラリなしの素の HTML / CSS / JavaScript で動作します。

## 遊び方

```sh
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

または `index.html` をブラウザで直接開いても動作します。

2人で1台の端末を使用します。自分の番以外は画面を見ないようにしてください。行動を終えると「交代してください」という画面が挟まるので、相手に端末を渡してからタップして再開します。

## ルール概要

- 5×5マス（列 A〜E、行 1〜5）の海戦図に、各プレイヤーが以下の3隻を1マスに1隻ずつ配置する。
  - 戦艦 (W) 耐久 3
  - 駆逐艦 (D) 耐久 2
  - 潜水艦 (S) 耐久 1
- 配置は互いに秘密。自分の艦同士は重ならないが、相手の艦とは重なってもよい。
- 手番では「攻撃」か「移動」のどちらかを行う。
  - **攻撃**: 自分の艦に隣接する（斜めも含む）マスにしか攻撃できない。命中すると耐久が1減り、0になると撃沈。攻撃したマスに自分（防御側）の艦が隣接している場合は、その艦種とともに「水しぶき」を申告する（命中の有無に関係なく発生する索敵情報）。
  - **移動**: 東西南北のいずれか1方向に、1隻だけ好きなマス数移動できる。移動先が自艦と重なることはできない。
- 相手の艦をすべて撃沈したプレイヤーの勝利。

## ファイル構成

- `index.html` — エントリーポイント
- `style.css` — 見た目
- `script.js` — ゲームロジックと画面描画（バニラJS、状態に応じて `#app` を再描画するシンプルな実装）
